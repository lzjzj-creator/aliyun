## 证据优先与安全边界

- 路由前置拦截：超范围直接拒答，改简历引导到简历助手，模糊问题反问。
- 检索阈值：最高分不足 0.25 时不调用模型编答案，直接说明资料不足。
- 提示词约束：只根据给定资料回答；资料不足必须明说。
- 简历改写：STAR 结构 + `【待补充：…】` 占位符 + 数字溯源守卫；原文没有的数字强制标记 `needs_user_data` 并生成确认问题。
- 知识库解耦：接口、前端、镜像 HTML 均不出现原站域名，来源只指向自建镜像 / GitHub Pages。

## 可复现性说明

- 路由评测依赖线上 `decision-model-preview`，存在少量边界波动，单次结果可能变化；报告采用连续 3 次运行的稳定结论。
- RAG 评测包含模型生成，耗时可受 FC 冷启动影响；脚本默认超时 120 秒。
- JSON 结果可通过 `--json-out` 输出，例如：

```bash
python tests/route_cases.py --json-out /tmp/route-eval.json
python tests/rag_e2e.py --json-out /tmp/rag-eval.json
```
