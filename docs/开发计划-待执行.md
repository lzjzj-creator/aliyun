## 部署顺序（用户授权 AccessKey 后）

1. `bash deploy/deploy-fc.sh` → 拿到两个 `*.fcapp.run` 域名
2. 前端 `frontend/.env.production` 写入 `VITE_API_BASE=<zhimai域名>` 和 `VITE_ANALYZE_URL=<analyze域名>/api/analyze`
3. `npm run build` → Qoder 会话里 `sites prepare_site` → `publish_site` → 拿 Sites URL
4. 把 Sites URL 回填两个服务的 `ALLOWED_ORIGINS`（重跑 deploy-fc.sh 即可）
