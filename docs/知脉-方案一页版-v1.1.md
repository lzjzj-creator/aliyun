# 知脉·简历成长助手 —— 参赛统一方案（一页版 V1.1）

**做什么**：双板块求职工具网页——
1. **知识问答**：问求职/实习/规划 → 从 1945 篇知脉笔记检索 → 流式回答 + 来源链接，查不到明说不硬编；
2. **简历助手**：上传简历 → 五维诊断雷达图 → STAR 逐条改写（缺数据反问，不虚构）→ JD 岗位匹配 → PDF 模板导出。

**两个招牌差异点**：
- **Decision Layer**：一个入口，三层级联路由（关键词→语义→小模型）判断你要"问答"还是"改简历"，自动引导跳转——评委看得到的 agent 设计；
- **闭环**：改简历时引用知识库里的求职方法论，问答时一键跳简历页，两板块互相输血。

**技术拼图**：
- 前端：新建 Vite 单页应用（双 Tab），部署 Qoder Sites 静态托管
- 后端：扩展现有 CloudBase FastAPI 服务，加 `/api/route` 和 `/api/resume/*`
- 数据库：Supabase + pgvector，知识库全量入库
- 模型：百炼 Qwen 主力（学生额度）+ DeepSeek 兜底；BGE-M3 向量
- 简历诊断：复用已上线的 analyze 引擎（证据缺口模型），不重写
