# 知脉 3 分钟演示脚本

> 目标：一条录屏同时证明「知识问答有来源」「简历改写不虚构」「Decision Layer 会分流」。
> 录屏前先打开线上站并保持网络畅通；冷启动时先点一次「演示问答」暖场。

## 0:00–0:25 开场

打开 https://zhimai-resume-uxvajmzewfe.qoder.zone

口播：

> 这是知脉，一个证据优先的大学规划与简历助手。它只解决两件事：回答要有出处，改简历不能编。

## 0:25–1:15 知识问答 + 来源

1. 点「演示问答（离线快照）」；
2. 等路由徽章出现后停 2 秒，指出：意图「知识问答」、知识域「大二大三」、置信度 99%、决策层「决策模型」；
3. 滚到来源区，点开第 1 条来源卡片，展示 GitHub Pages 镜像原文；
4. 返回产品页。

口播：

> 每个回答都先过 Decision Layer，再检索 2790 篇笔记、5576 个分段。来源是真的能点开核对；检索分不够时它会直接说不知道。

## 1:15–2:20 简历诊断 + JD

1. 切到「简历助手」→「示例演示」；
2. 展示五维诊断与问题清单；
3. 在 JD 框粘贴一段前端岗位 JD，点「开始分析」；
4. 展示岗位覆盖率、命中关键词、缺失关键词；
5. 指出「改写就绪度：需先补充事实」以及它反问的具体问题。

口播：

> 它不会为了好看替学生编 TypeScript、接口联调或 Git 经验。简历里没有证据，就停在补事实这一步；所有新数字都必须用户确认。

## 2:20–2:45 管理后台

1. 新标签打开 `https://zhimai-resume-uxvajmzewfe.qoder.zone/#admin`；
2. 输入密码登录；
3. 展示文档 / 分段统计和最近入库，搜索一个标题。

口播：

> 公开站保持开放评审，管理入口是隐藏路由，密码和会话校验都在服务端，前端拿不到密码。

## 2:45–3:00 收尾

切回首页，口播：

> 前端 Vue 3 部署在 Qoder Sites，两个后端跑在阿里云函数计算，知识库镜像在 GitHub Pages。路由评测 30 条 96.7%，RAG 10 条全部有来源。代码在 GitHub `main` 分支。

## 录屏注意

- 不要展示 `.env`、后台密码、Supabase / DashScope 密钥；
- 管理后台只展示统计和公开标题，不搜索敏感内容；
- 若真实接口冷启动超过 5 秒，先切到演示快照，避免录屏空等；
- 分辨率 1920×1080，浏览器缩放 100%，关闭无关标签页和通知。

# v2 演示脚本（简历向导域，B 侧已可跑通）

> 前置：后端 `uvicorn main:app --port 8788` + 前端 `npm run dev`（`/api` 代理自动转发）。
> 会话存储未就绪前，全部走「演示素材」降级路径，不依赖 A 域接口。

## 契约演示（离线）

1. 打开 `#/demo`：展示契约渲染器按 `resume_template.json` 自动渲染——改契约即改版式；
2. 口播：模板契约是 B 监护的单一事实源，访谈提纲、覆盖率、填写 schema、渲染、优化评分全从它推导。

## 一键填写

1. `#/resume` → 点「演示素材」载入 8 轮访谈会话（demo session）；
2. 点「一键填写」：真实调用 `/api/v2/resume/autofill`；
3. 展示：字段自动填充、缺证据字段留空并入 gaps 黄标（姓名/电话/实习等 ~10 处）、悬停字段看出处引文；
4. 口播：每个字段都有证据出处，AI 没挖到的一律黄标，不替你编。

## 修改 + 预览导出

1. 下一步：左表单右实时预览，改一个字预览即变，自动存本机；
2. 点「导出 PDF」→ 浏览器打印只出预览稿（表单/按钮全部隐藏）。

## 黑箱优化

1. 下一步 → 「一键优化」：plan 按含金量排序（internships 空节自动跳过）；
2. 逐段跑，每段显示 steps（诊断→改写→守卫）；
3. 展示 change_log 前后对比 + **守卫拦截**：真实调用里 `99.8%`、`P95`、`QPS`、「购物车」式扩写全部被拦成占位 + 反问确认；
4. 「采纳优化稿」→ 优化稿对比预览（绿标显示改动）；导出前有占位会二次确认。

口播：

> 优化的红线是"不虚构"：编造数字、编造职责范围都会被守卫拦下来变成待补充占位和反问，原文一个字不丢，优化稿另存。
