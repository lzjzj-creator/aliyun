# 开源借鉴与许可登记

本项目代码均为原创实现；下表登记 v2 设计过程中参考过结构/协议/版式/措辞的开源项目。
凡标「借鉴点」而非「代码引入」的，均未复制其源码，无附带 LICENSE 义务；
MIT/Apache-2.0 均允许借鉴再创作，此处登记仅为溯源与合规留痕（issue #24）。

## 字段共识（非开源来源，调研登记）

- 牛客校招简历帖 × ATS 指南交叉验证的字段集：求职意向紧随姓名、实习>项目排序、
  每条≥1 量化数据、技能分组分档、不写籍贯/政治面貌——已固化进 `resume_template.json` 的
  `rules`/`rubric` 字段。
