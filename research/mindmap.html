技术与部署
  • 前端：Vue3+Vite+Tailwind → Qoder Sites
  • 后端：FastAPI on CloudBase（复用队友服务）
  • 数据：Supabase Postgres+pgvector
  • 生成：百炼 qwen-plus（DeepSeek 兜底）
  • 分类：qwen-turbo；向量：BGE-M3
16 天里程碑
  • D1 后端健康+Supabase schema+百炼key
  • D2-3 前端骨架+接通问答流式
  • D4-7 路由L1-L3+意图评测集+简历解析/诊断
  • D8-11 改写+DiffView+PDF导出+JD匹配

评测与风险
  • 路由准确率 ≥92%（50-80条语料）
    • L1/L2 分流占比 = 成本优势证据
  • RAG：Top-K召回/来源匹配/拒答率/P95
  • 权限：public+ready 过滤不泄漏
  • 风险：后端503/跨云延迟/隐私/超支
    • 砍单序：微调→JD→对比→PDF精排

Decision Layer 意图路由
  • L1 规则快通道：强关键词/带附件
  • L2 语义路由：bge-m3 × 示例语料
    • top1≥0.72 且 margin≥0.08 才放行
  • L3 qwen-turbo JSON 分类兜底
    • 置信度低 → 反问澄清
  • 意图：kb_qa / resume_edit / resume_qa / chitchat / out_of_scope

板块A：RAG 知识问答
  • 混合检索：向量 0.7 + 关键词 0.3
  • 流式输出 + 来源引用（文件/页码）
  • 无依据拒答 + 建议问法
  • 简历意图 → RouteGuideCard 导流卡
  • 引导问题 / 多轮追问 / 赞踩反馈
